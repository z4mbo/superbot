# Service logos

Each file is named for the `MCP_SOURCE_PRESETS` id it marks
(`packages/core/src/integrations/featured-connectors.ts`).

The artwork is from [Simple Icons](https://simpleicons.org) 15.4.0, released under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md), with each
path filled in the brand colour Simple Icons records for it. The marks are trademarks of their
owners and are shown only to identify the service a person connects to.
