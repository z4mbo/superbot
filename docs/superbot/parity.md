# Superbot capability coverage

Superbot's existing web app, Electron web shell, Expo app, and backend are retained. This map records what the new Rust libraries expose. A native service entry means Rust callers can use the operation via the listed upstream path. Desktop and CLI screen or command wiring is outside the scope of this map.

Paths are relative to `/rpc/` unless an absolute path is shown. Names in braces represent exact path alternatives. The source of truth is the [shared RPC contract](../../packages/contracts/src/rpc/app-contract.ts) and the [API router](../../apps/api/src/router.ts). The route status is based on the server source at baseline `c742a0799`.
