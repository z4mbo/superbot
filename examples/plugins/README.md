# Plugin examples

- [MCP server](mcp-server/README.md): wrap a hosted MCP server with an optional skill.
- [Hello world](hello-world/README.md): a skill without an MCP server.

Copy an example into a public GitHub repository, then follow [Build a plugin](../../docs/build-a-plugin.md)
to test and submit it. Superbot reads the plugin files without running repository code.

## Marketplace manifests

- [Calorie diary](kcal-diary/README.md) is a record app: a form whose entries Superbot keeps and totals.
- [T3 Code inbox](t3-coding/README.md) lets people and bots propose coding work for an operator to start in a selected T3 Code project.
