# Team dashboard

An example app built with the plugin SDK: open tasks, shipped work and the team's status, kept by
people and bots together. See [Build an app](../../docs/plugin-sdk.md).

```sh
pnpm app:check examples/team-dashboard
```

This folder is not a workspace package and is not bundled into any app. Its tests live with the
SDK (`packages/plugin-sdk/src/node/app-folder.test.ts`).
