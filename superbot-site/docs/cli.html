superbot-plugin commands

The author and admin tool for the plugin registry. Registry commands print JSON.

Options for every command

OptionWhat it does
--server URLThe Superbot server. Also read from SUPERBOT_SERVER. Use the same one you signed in to with superbot login.
--space NAME|IDWhich Space to act in, by exact name or ID. Needed only if you belong to more than one.

Writing and publishing

CommandWhat it does
init SLUG [--template skill|mcp-app|kcal-diary] [--name NAME] [--manifest FILE]The default skill starter writes plugin.json with one part, summary. The mcp-app starter also writes a runnable TypeScript tool server and its README alongside the manifest; it is a tool server, not a record app. The kcal-diary starter writes only plugin.json: the Calorie diary record app, ready to edit. Alias scaffold.
validate [FILE]Checks the manifest against schema 1 locally, without contacting the server, including record app fields.
publish SLUG VERSION [--manifest FILE]Submits a version for review. VERSION is a whole number from 1. Alias submit.
status VERSION_IDShows one of your versions, its status and any rejection reason.

superbot-plugin doesn't read or write record app entries. People use the store, programs use the registry API, and local models use the chat commands below.

Lists

list SCOPE [--after CURSOR] [--limit N], where N is 1 to 50 (default 20). When there's another page, the JSON includes nextAfter; pass it as --after with the same scope and filters.

ScopeLists
discoverApproved versions. The default. Search by name, description or ID with --query "release notes", or filter by exact ID with --slug SLUG.
mineYour own submissions, with their status.
installationsYour installations in the selected Space, with their grants.
submissionsThe review queue, for deployment admins. Filter with --status pending|approved|rejected.

Installing and granting

CommandWhat it does
agentsLists the selected Space's bots and their ids, for grants.
install VERSION_IDInstalls an approved version into the selected Space.
switch-version INSTALLATION_ID CURRENT_VERSION_ID TARGET_VERSION_IDSwitches to another approved version of this plugin and clears the old grants. A failed switch leaves the current state intact.
set-grants INSTALLATION_ID BOT_ID [PART_ID...]Replaces that bot's parts for the installation. No part ids revokes them all. Alias grant.
uninstall INSTALLATION_IDRemoves the installation and every grant it has.

Reviewing

CommandWhat it does
review VERSION_ID approvedApproves a pending version. Deployment admins only.
review VERSION_ID rejected --reason TEXTRejects it. The reason is required and shown to the publisher.

Record apps in superbot chat

When a bot answers through a supported local model, open its chat with superbot BOT_NAME and use these commands. See local models.

CommandWhat it does
/appsLists the record apps granted to this bot, numbered.
/app N [--date YYYY-MM-DD] [REQUEST]Shows recent entries of app N, filtered by its first date field. With a request, asks the model about them.
saveSaves the entry the model proposed, after you review its fields. Press Enter to skip it.
/app retryRepeats a save that wasn't confirmed, without creating a second entry.
/app discardStops retrying a save that wasn't confirmed.

Errors

Messages from both programs, with their fixes, are in Errors and fixes.
