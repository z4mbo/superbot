Errors and fixes

Messages are quoted as Superbot prints them. Find yours with your browser's search, then read the cause and the fix beside it.

How errors arrive

WhereShape
superbot-plugin validateA sentence naming the part or field to fix. Nothing is sent to the server
Registry APIA status and a message: BAD_REQUEST 400, UNAUTHORIZED 401, FORBIDDEN 403, NOT_FOUND 404, CONFLICT 409. superbot-plugin prints the message
A bot's tool callThe bot receives an error result and tells you in chat. No data changes
