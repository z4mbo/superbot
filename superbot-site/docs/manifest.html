Manifest reference

Schema version 1. The server rejects any manifest with a field not listed here.

Top level

FieldTypeRules
schemaVersionnumberAlways 1.
namestring1 to 120 characters after trimming. Shown in the store.
descriptionstring1 to 1,000 characters after trimming. The first two lines show on the store card.
partsarray1 to 16 parts. Part ids must be unique within the manifest.

The slug and the version number are not in the manifest. You send them beside it when you submit.

Part ids and slugs

Part ids and plugin slugs follow the same pattern: 1 to 64 characters, lowercase letters and digits, words joined by single hyphens.

notes, issue-tracker and v2 are valid. Notes, issue_tracker, -notes and a--b are not. People grant parts to bots by id, so keep an id stable across versions when the part does the same job.

Skill part

FieldTypeRules
idstringSee part ids.
kindstring"skill"
instructionsstringMarkdown, 1 to 16,000 characters after trimming.

Tool part

FieldTypeRules
idstringSee part ids.
kindstring"mcp"
transportstring"streamable_http", the only transport.
endpointstringA public https:// address with no credentials, query string or fragment.

The registry checks the endpoint during review. At runtime the server refuses redirects and private addresses, rechecks that the grant is still in place, and asks a person to approve every call after showing the endpoint and the arguments. In a Space set to Never ask, calls are refused.

Record app part

A record app declares fields. The server stores entries with those fields and shows them in Superbot's standard form and list.

FieldTypeRules
idstringSee part ids.
kindstring"app"
fieldsarray1 to 16 fields with unique ids.
summaryFieldstring, optionalThe id of a number field to total.

Each entry in fields has exactly these four properties:

FieldTypeRules
idstringSame pattern as part ids. Keep it stable across versions.
labelstringUp to 120 characters, not blank, without text-direction control characters. Shown in the form and to bots.
typestring"text", "number" or "date".
requiredbooleanAlways written out, true or false.

Saved values follow the field type. Text holds up to 2,000 characters and can't be blank. A number is finite, between −1012 and 1012. A date is a calendar day written YYYY-MM-DD. An optional field may be left out of an entry. The first date field, in manifest order, is the one people and bots filter by day. The total adds up the summaryField of every entry that matches.

What a manifest can't contain

  • API keys, tokens, passwords or HTTP headers. If your server needs sign-in, use OAuth on the server; people sign in when they connect it.
  • Commands, packages, scripts or install hooks.
  • HTML or JavaScript. Superbot draws record apps from their declared fields. A tool server can serve its own view, which runs in a sandbox.
  • Local or private addresses such as localhost, 127.0.0.1 or 10.0.0.0/8.
  • Any field not listed on this page, at any level.
