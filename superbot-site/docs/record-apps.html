Record apps

A record app is a list of fields. Superbot stores the entries, draws the form, the list and the total, and gives granted bots two actions. You write no code and run no server.

When to use one

You wantUse
Entries a person and their bot both keep, such as meals, expenses or requestsA record app
To teach a bot how to do somethingA skill
To reach your own service, or show a custom interactive viewA tool server

Superbot draws every record app the same way. A manifest can't change the layout or bring its own HTML or JavaScript.

Design the fields

  • Types. text holds up to 2,000 characters and can't be blank. number is between −1012 and 1012. date is a calendar day written YYYY-MM-DD.
  • Required. Write required on every field. People and bots may leave optional fields out.
  • Labels. People see the label in the form and bots see it in the tool description, so name the unit: Calories (kcal), not Amount.
  • Day filter. The first date field, in manifest order, is the one people and bots filter by day.
  • Total. summaryField names a number field. The total covers every matching entry, not only the page on screen.
  • Ids. Field and part ids are stored with every entry. Keep them stable across versions.

One plugin can hold up to 16 parts, so several apps and a skill can work together. The T3 Code inbox uses two apps and a skill.

What people see

After installing, a person opens the app from Installed. They can pick a day or All dates, read the total, add an entry with the form and remove entries. Entries can't be edited in place: remove one and add a corrected entry.

What a granted bot gets

ActionInputApproval
List entriesdate?, after?, limit?. Returns entries newest first and the totalNone. It only reads
Add an entryvalues, checked against your fieldsEvery time. A person sees the values and chooses Allow once. Never ask refuses it

Bots can't remove entries. They get these actions only in a direct chat with the installer, in a turn the installer's own message started. A bot answering through a model CLI on your computer gets no tools: you share entries with it yourself through /apps in superbot. The full rules are in People, bots and permissions.

Data, versions and uninstall

  • Entries belong to one installation: one account in one Space. Other members of the Space install their own copy and never see yours.
  • Each version keeps its own entries. After switching versions you see that version's entries, and switching back shows the earlier ones.
  • Turning off a bot's grant keeps the entries.
  • Removing an entry erases its values. Uninstalling permanently deletes the entries of every version.

Write and publish one

The kcal-diary template is the only app starter: edit its fields before validating. Create plugin → Add app in the store builds the same part with a form. The quickstart walks through every step, including review and testing on your own server.
