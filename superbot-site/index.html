A plugin is one small manifest

No packages, no install scripts, no secrets. A plugin describes what it adds; the server checks it and a reviewer approves it.

  • SkillsMarkdown instructions that teach a bot how to do something. Bots treat them as untrusted input.
  • ToolsA remote MCP server on a public HTTPS address. Before every call, a person sees the destination and the arguments and chooses Allow once.
  • Grants per botInstalling adds nothing to any bot. People switch on each part for each bot they choose.
  • Pinned versionsApproved versions never change. An installation stays on its version until someone switches it.
